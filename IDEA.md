Queria fazer um projeto de webapp sobre Pokemon que irá ter como features por agora as seguintes :

- Pokedex interativa:

Com pesquisas, e filtros dinâmicos, como filtro por tipo, geração, etc... Ao clicar no pokemon teria a sua imagem,
seguido do seu nome e número na pokedex como é normal, para além disso teria, moves aprendidos através de leveling,
de TMs, habilidades possíveis, melhores naturezas, fraquezas e resistências,  etc... Comparações entre pokemons em que mostrará gráficos interativos do tipo radar para comparar atributos base de dois até 4 pokemons, mostrando também por baixo possíveis habilidades, leveling learned moves, melhores naturezas, etc... Quero também que tenha sons ao abrir a pagina do pokemon e que a imagem deles seja em sprite animado

- Adições para fazer mais tarde:

Fazer um Team builder em que se escolhe 6 pokemons, em que se pode definir habilidades dos pokemons escolhidos dentro das possíveis desses pokemons, definir movesets e held items, que faça análise de fraquezas e resistências dessa equipa, onde se encontra lacking e onde residem as suas forças, e dicas para a melhorar ou sugestões…


Em relação a arquitetura tenho algumas sugestões, REACT com uma API pública como PokeAPI, API robusta em Java ou DJango, uso de Node.js, quanto à API não sei se devo usar a API publica referida ou uma base de dados relacionar fiável como PostgreSQL
